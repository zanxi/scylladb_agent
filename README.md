Приложение клиент на основе qwebsocket бибиотеки позволяет просмотреть, редактировать структуру базы данных SCYLLADB.
Для связи используется websocket многопоточный сервер написанный на qtc c++ с использованием
бибилитеки datastax.
.....
Добавлены исправления для qt 6.10.2 чтобы проект компилися для WebAssembly - agent доступен черз webbrowser (последний скрин)
